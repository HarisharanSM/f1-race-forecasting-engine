# Continuous backtest for 2020-2025

For the later joint driver/car comparison through completed 2026 sessions, see
[Joint-effects backtest: 2020-2026 YTD](JOINT_BACKTEST_2020_2026.md).

This experiment evaluates the revised learned-measurement model with validation
calibration against a fresh original-input Transformer baseline. Both models use
the same expanding training history, target sessions, seed and simulation count.
The readable report combines Grand Prix and sprint forecasts using the existing
year, circuit, session and weather-scenario workflow.

## Recorded results

The completed run evaluated 284 forecasts across 126 calendar weekends: 248 Grand
Prix forecasts and 36 sprint forecasts. The source contains 331 records, including
41 Grand Prix records from the 2019 warm-up season and six 2021 sprint development
records. All available, eligible 2020-2025 sessions were accounted for.

Average expected-position error fell from 3.223387 to 3.207334, a 0.4980% reduction.
Winner/pole picks increased from 130/284 (45.7746%) to 131/284 (46.1268%). Pairwise
ranking accuracy was essentially unchanged: 77.2465% to 77.2445%.

Probability quality was mixed. Winner Brier improved from 0.768706 to 0.760355,
but position log loss worsened from 2.672214 to 2.678628. Mean displayed confidence
rose from 11.9437% to 12.4139%; this increase alone is not evidence of better
calibration. Nominal 80% interval coverage decreased from 87.2229% to 86.4474%,
while mean interval width narrowed from 10.7405 to 10.4896 positions.

The 95% paired-weekend bootstrap interval for the position-error change was
-0.023937 to -0.008633 positions. The interval for Brier change was -0.012083 to
-0.004838, while the log-loss change interval was -0.003265 to +0.016476. These
resampling results do not remove the historical and training-dependence limits
described below.

The optional correction was selected in 5 of 126 Grand Prix folds and no sprint
folds. Pace temperature changed in 35 Grand Prix folds and nine sprint folds.
The timing collection enriched 36 Grand Prix snapshots and eight sprint snapshots.
Most evaluated sessions therefore test calibration with original inputs.

Verification confirmed source manifest hashes, exact paired sessions, chronology,
target-weekend exclusion, model-selection cutoffs and coverage accounting. All
162 earlier 2020-2023 original-input forecast distributions reproduced the prior
deterministic experiment exactly. The combined report validated its exact source
datasets. All 162 code tests passed, as did lint, formatting and diff checks;
three dependency deprecation warnings remain.

## Historical coverage

The original 2019-2023 and 2024-2025 Grand Prix datasets are joined into one
chronological history. The 2019 season initializes training; the evaluation starts
in 2020 and includes 2024, which was only development data in the previous recent
experiment. The same continuous-history approach joins 2021-2025 sprint data.
Grand Prix and sprint models are fitted separately.

Grand Prix fitting requires eight training weekends and two validation weekends.
Sprint fitting requires one training weekend and two validation weekends. Using
two sprint validation weekends allows the revised measurement selector to meet
its evidence requirement. Consequently the three available 2021 sprint weekends
are development-only; sprint evaluation begins in 2022. These settings are shared
by both comparison arms. They differ from the previous sprint experiment, which
used one validation weekend.

Source manifests and the previous experiment's exact dataset hashes are verified
before merging. Missing classifications remain excluded, with their original
reasons carried into the combined report. No download or reconstruction is used
to fill missing outcomes. Same-calendar-weekend evidence is recognized for both
Grand Prix and sprint snapshots; format-specific event IDs remain distinct.

The currently available quality-aware timing collection supplies optional
measurements only for parts of 2024-2025. No optional telemetry measurements have
been added to 2020-2023. Earlier changes therefore reflect validation calibration,
not benefits from newly collected measurements. Stint observations, sample counts,
availability checks and quality indicators use the verified revised pipeline.

## Interpretation

The 2025 scores are not directly interchangeable with the earlier experiment that
trained only on 2024-2025. The expanded history changes model fitting, validation
and fold seeds. Use the fresh matched baseline in this report to measure the
revised model's effect.

Forecasts are fixed before their target outcomes enter later training windows.
Entire target weekends are excluded from fitting and validation. The last two
earlier validation weekends select the training epoch, optional correction and
pace temperature. They are development data, not an independent test.

Earlier weather uses labelled prior-practice persistence rather than archived
weather forecasts. Historical availability remains reconstructed. Shared Friday
qualifying results in 2021-2022 appear in both separately trained formats, so the
combined evaluation count is not a count of independent physical sessions.
Bootstrap comparisons resample whole calendar weekends, grouping GP and sprint
evaluations together. Training-seed variation, overlapping training histories,
regulation changes and prior inspection of historical results limit inference.

## Reproduction

```sh
uv run python scripts/backtest_2020_2025.py \
  --collection data/processed/performance-full-2024-2025 \
  --output artifacts/backtest-2020-2025-new
```

The command requires a new output directory. It saves merged source and enriched
datasets, source manifests, enrichment audits, both formats' full backtests,
matched statistics and readable combined HTML/CSV reports. It uses 60 maximum
epochs, patience 8, deterministic CPU execution, seed 42 and 1,000 simulations per
scenario. Existing experiments and model checkpoints are retained.

- Summary: `artifacts/backtest-2020-2025/comparison.html`.
- Revised report: `artifacts/backtest-2020-2025/revised-report.html`.
- Original-input report: `artifacts/backtest-2020-2025/baseline-report.html`.
- Exact statistics and intervals: `artifacts/backtest-2020-2025/comparison.json`.

See [learned measurements](LEARNED_MEASUREMENTS.md) for input definitions and
selection rules, and [earlier seasons](EARLIER_SEASONS.md) for archive limitations.
